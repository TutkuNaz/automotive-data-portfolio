# Roadmap

The repository is evolving from a portfolio index into a practical automotive open-data reference with reusable tooling.

## Near term

- Expand the catalog to 30+ high-quality first-party datasets.
- Add automated source-link health checks.
- Add category pages for safety, EV/charging, rental/mobility, maintenance and vehicle economics.
- Add downloadable JSON alongside CSV for programmatic use.
- Add one reproducible starter notebook per major category.

## Next

- Build a lightweight dataset browser with filters for geography, access type and license/terms.
- Add NHTSA reliability and recall examples.
- Add current EPA vehicle-efficiency examples.
- Add multi-year airport rental and passenger-demand analysis where definitions are consistent.
- Add an EV charging coverage project using official infrastructure data.

## Community

- Maintain clear contribution rules for dataset additions.
- Track broken links and source-definition changes through issues.
- Highlight external projects that use the catalog.
